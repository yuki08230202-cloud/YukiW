# 進捗管理シートの作成と共有

企画書のPDFができていることが前提。シートはクライアント1社につき1つ。総本数(例: 24本)分の行を、1回で作っておく。企画書は、できた分の行から順に埋める。

Googleのコネクタ(Drive、Sheets)が使えることを先に確かめる。使えなければ、ユーザーに自分の端末で接続をオンにしてもらう。Claude Codeでコネクタが使えないときは、シートの更新はユーザーがチャットでClaudeに頼む。

## 手順(初回)
1. 進捗管理のひな形をユーザーからもらう(Driveにあれば、その場所を聞く。xlsxを添付されたら中身を読む)。
2. ひな形がDriveにあるなら、`copy_file` で複製して、名前を「<クライアント名> 動画制作・投稿進捗管理」にする。複製が難しければ、新しいスプレッドシートを作って、値と書式をSheetsのツールで入れる。
3. 次を埋める。
   - 1行目: 「<クライアント名>様| 動画制作・投稿進捗管理」
   - 3行目: 目標本数(総本数)、投稿済み、残り本数、進捗率(数式はそのまま残す)
   - 5行目: 管理No.、動画タイトル、進行ステータス、台本・絵コンテURL、参考リンク、撮影素材URL、完成動画MP4 URL、投稿予定日、備考
   - 6行目以降: 1行に動画1本。管理No.は001から。進行ステータスは最初「台本確認中」。
   - 備考: ジャンル、秒数とカット数、要確認の要点。
   - 参考リンク: ユーザーが渡した参考動画のURL。
4. Driveに、クライアント用のフォルダを作る。ユーザーに、企画書のPDFをそのフォルダへアップロードしてもらう。

## 毎回(企画書を足すとき)
1. ユーザーにPDFをフォルダへアップロードしてもらう。
2. フォルダのPDFを検索して、各ファイルのIDを取る。「台本・絵コンテURL」の列に `=HYPERLINK("https://drive.google.com/file/d/<ID>/view","企画書①を開く")` を入れる。タイトルと進行ステータスは、該当の行だけ更新する。
3. ユーザーが手で直したセル(タイトルや備考)は上書きしない。更新する前に、現在の値を読む。
4. 書き込んだ値を読み戻して確かめる。

## 共有と連絡
- 共有設定を確認する。リンクを知っている全員が「編集できる」になっていたら、ユーザーに伝えて、閲覧者にするか確認する。
- 固定行を0にする。上の5行を固定したままだと、スマホで画面が埋まって下の行が見えない。
- LINE文を2案作る(下のひな形)。

## 注意(今回わかったこと)
- ClaudeのアーティファクトのURLは、Claudeにログインしている人しか開けない。クライアントに渡すリンクには使わない。
- Claudeのツールから、大きなファイル(数百KB以上)をDriveにアップロードするのは難しい。base64が途中で切れて失敗する。PDFやWordは、ユーザーに手でアップロードしてもらう。
- Wordのままリンクすると、Driveのプレビューで1ページ目以外が崩れることがある。PDFで渡す。
- 画像を入れたGoogleドキュメントは、ここからは作れない(画像の公開URLが要る)。文字だけのドキュメントになるので使わない。
- Claudeのツールでは、ファイルを「リンクを知っている全員」に共有することはできない。共有はユーザーが行う。メールアドレスがわかれば、個別に共有はできる。

## LINE文のひな形
「お疲れ様です。<クライアント名>さんの動画の企画書を<本数>本作成しました。明日の<時刻>にミーティングよろしくお願いします。下のシートから企画書をご確認いただけると助かります。<シートのURL> ご確認よろしくお願いします。」
日付と時刻は、ユーザーの言うとおりにする。
