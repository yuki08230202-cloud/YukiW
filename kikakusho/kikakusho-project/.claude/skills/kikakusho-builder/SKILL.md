# 動画企画を企画書に落とす

## 前提
- 企画のあらすじはユーザーが出す。Claudeは、それを台本と企画書にする役。企画そのものを勝手に増やさない。
- 1社あたりの総本数は多い(例: 24本)。一度に作るのは、今回頼まれた本数だけ。号数(番号)は、前回の続きから振る。
- 先に `client-intake` で事実を整理しておく(`clients/<社名>/facts.md`)。整理がないときは、資料を先に依頼する。

## ユーザーからもらうもの
1本の企画ごとに、次を聞く。無いものは、聞くか、仮案として印をつけて進める。
- 企画のタイトルと、狙い(誰に、何を伝えるか)
- 参考動画(ファイルやURL。ない企画もある)
- だいたいの尺、ジャンル(エンタメ、求人訴求、密着、インタビューなど。例で、固定ではない)
- 出演者の有無

## 進め方
1. 伝える相手(職種、年齢、立場)を確かめて、台本を先に作る。ユーザーに読んでもらい、直しを反映してから企画書にする。
2. `clients/<社名>/project.json` に、企画のデータを書く(書き方は `tool/README.md`)。
3. 文章の決まりで全文を見直す。
4. `node tool/build.js clients/<社名>/project.json --out clients/<社名>/out --pdf` で Word と PDF を作る。
5. PDFをページ画像にして、全ページを目で見て確認する。
6. Word と PDF をユーザーに送る。

## 企画書の構成
表紙側: 題名、想定秒数、カット数、縦型9:16 / 参考動画(動画名とリンク) / 画の作り方 / 演者 / 撮影条件 / 撮影前に揃えるもの / 編集とリアクション / 通し台本(C-01から順) / 要確認事項(仮案。クライアントに聞く点)

カット表(3列、1ページに3カットほど): 画面/絵(カット番号と画像) | 内容&セリフ(「① 撮影指示」:場所、動き、参考動画の何秒か、「② セリフ/テロップ」) | 時間(秒数、開始〜終了、累計)
各ページの下に「<クライアント名> 絵コンテ | ページ数」を入れる。
インタビューのように画角が変わらない企画は、カット表を作らず、画角図と進行表(秒・話者・セリフ・テロップ)にする(`"type": "interview"`)。

## 画像の扱い(重要)
- 参考動画のスクリーンショットは載せる。project.json のカットに `frame` を書くと、その秒の画像が入る。
- Claudeが描いた絵やイラストは載せない。その欄は空欄にする。ユーザーは、Claudeが作った絵コンテ画像を求めていない。
- 見本の企画書に人型イラストがあり、ユーザーが渡した場合だけ、それを使ってよい。「姿勢と構図を示す仮の素材」と注記する。
- 参考画像のあるカットには「参考動画 0:12」のように秒数を書く。
- 参考画像には、他社の文字や人物が入る。表紙に注記が自動で入る(project.json の `reference_note` で変えられる)。

## 文章の決まり
- 短い文にする。1文に1つのことだけ書く。
- AIっぽい言い回しを避ける。例: 「リズム」「距離感」「寄り添う」、台本以外の「ちゃんと」、体言止めの連発、「〜という」の重ね。
- 数字、条件、設備は、クライアントの資料にある事実だけを使う。資料にないことは書かない。
- 仮の内容には「(仮案)」をつける。確認が要る点は「要確認事項」に集める。
- 事実と違うおそれのある言葉(「未経験OK」など)は入れない。
- 参考動画の台本を丸写ししない。構成の型だけ借りる。

## 技術メモ
- 台本とテキストは1つのJSONにまとめる。直しはJSONに対して行い、Wordを再生成する。Wordを直接いじらない。
- 作業フォルダはスクラッチパッドを使う(Claude Codeなら、プロジェクトの `clients/` の下)。
